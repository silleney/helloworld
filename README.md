# 小账 · 极简语音记账本

免费的本地个人记账 PWA，完成需求中的阶段 A。React + TypeScript + Vite，IndexedDB 持久化，离线资源由 Workbox 缓存。没有云数据库、账户、收费 API、域名购买或云资源开通。图表使用轻量 CSS 绘制，避免额外图表依赖。

## 运行

推荐 Node.js 24（`.node-version`），npm。使用现有仓库，无需另建 worktree。

```sh
cd /workspace/helloworld
npm ci
npm run dev
```

开发服务器默认端口 5173。普通本地开发可用 HTTP；手机使用 PWA、网页麦克风需可信 HTTPS。开发模式不注册离线 Service Worker。

验证生产与离线版本：

```sh
npm run build
npm run preview -- --port 4173
```

将 `dist/` 作为静态站点提供即可；预览服务器用于本地验证，不是生产部署。**浏览器来源（协议、主机、端口）改变会形成独立账本**，迁移时先导出 JSON 再恢复。

## 功能与使用

- 首页：本月总额、必要/非必要金额和占比、最近五笔账目、快速记账。
- 输入“今天买菜花了38块，买零食花了25块”，点击“识别账目”。消费内容、金额、日期、分类全部可修改，点击确认后才入账。
- 支持 `38元`、`三十八块`、`12块5`、`12.50元`、`一百二十元五角`；支持“今天/昨天/前天”和 `YYYY-MM-DD`。不明确的金额、缺失内容提供提示，不编造信息。没有金额单位时请用手动记账。
- “手动记账”：内容、正数金额（最多两位小数）、本地消费日期和分类必填。
- 分类仅有“必要生活开支”和“非必要开支”。关键词提供建议；咖啡、衣服、外卖、礼物和未知内容保留待确认。相同名称的最新历史选择优先。
- 流水：按日期倒序、月份切换、编辑、确认删除、当前页面撤销最近一次删除。
- 统计：真实账目计算的月总额、两类金额与占比、截至所选月份的六个月趋势。没有预置演示账目。
- 成功与失败均有提示；批量保存使用原子事务，连续提交有互斥保护；账本上限 10 万笔，总额超过安全整数范围会拒绝整批写入。未提交文字和新账草稿尽量保存在本地；编辑中的草稿不会跨刷新恢复。

## iPhone 听写与 PWA

1. 在 Safari 打开可信 HTTPS 站点，点击首页输入框。
2. 点击 **iPhone 系统键盘** 的麦克风进行听写；确认系统设置已开启听写。听写结束后检查文字，再识别、修正并保存。
3. 网页麦克风按钮仅在浏览器提供 Web Speech API 时显示。权限拒绝、网络问题、不支持或取消时都不会自动入账；可继续手动输入。识别按钮不调用大模型。
4. Safari 分享 → **添加到主屏幕**。首次访问需联网，生产包资源缓存完成后可以离线记账。浏览器语音和系统听写是否离线可用取决于设备及语言资源，本应用不保证。
5. 新版本有更新提示，先保存或取消草稿并清空输入，再更新，避免打断记账。

系统键盘听写与普通键入无法可靠区分，记作 `source: manual`；网页语音识别记作 `source: voice`。真实大陆版 iPhone 13 的 Safari、系统听写和桌面安装仍需实机验收，未用模拟屏幕测试冒充实机验证。

## 备份与恢复

顶部“仅当前浏览器”或桌面“设置与备份”打开设置。

- **CSV**：导出全部账目，人民币元显示、UTF-8 BOM、CSV 转义及公式注入防护。用于查看，不用于恢复。
- **JSON**：包含 `version: 1`、导出时间和全部完整记录；是迁移、恢复的唯一支持格式。
- 恢复：文件最大 20 MB，最多 10 万条；完整验证字段、日期、整数金额、分类、来源和 ID，再展示恢复确认。任何异常记录取消整份导入。
- 按 ID 去重；相同 ID 且内容一致跳过，相同 ID 内容不同拒绝整个导入，不覆盖本地编辑。重复消费只要 ID 不同，视为不同账目。
- 备份合并现有账本，不清空现有数据。删除后恢复旧备份会重新加入该记录，这是恢复功能的预期行为。

数据仅在当前浏览器的 IndexedDB 中，**没有跨设备同步**。清除网站数据、隐私浏览、浏览器存储回收、卸载或设备故障均可能导致丢失，请定期保存 JSON 到你信任的位置。备份包含消费明细，请妥善保管。

本地版没有用户账号，同一浏览器配置下共用账本；不同浏览器配置/来源各自隔离。多账号权限隔离属于待确认的阶段 B，当前请勿将其用作多人共用账本。

## 自动化测试

```sh
npm test                 # 解析、金额、日期、分类、备份、IndexedDB
npm run build            # TypeScript 检查及生产 PWA
npx playwright install chromium webkit
npm run test:e2e         # 桌面、手机尺寸 Chromium，以及 WebKit
```

如果环境已有 Chromium，可不下载浏览器：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:e2e -- --project=desktop --project=iphone-size
```

Playwright 自动启动生产预览服务器（4173）；若该端口已有本项目服务器则复用。每个用例使用独立浏览器数据。WebKit 项目需要相应浏览器与系统依赖，不可将缺失浏览器当作测试通过。

完整结果与未验证项见 [测试报告](docs/TESTING.md)。云同步候选、核实条件和下一阶段设计见 [云服务研究与阶段 B 接入方案](docs/CLOUD-PLAN.md)。进入阶段 B 之前需要用户确认。

## 已知限制

- 文字解析是规则解析，不支持任意复杂语义、所有金额说法或所有日期格式。含范围、近似、缺失或多义金额请手动填写；核对提示后再保存。
- 没有账户、服务器、云同步或自动备份，没有加密本地数据库。数据访问依赖当前浏览器配置。
- 新账草稿尽量保留，编辑草稿刷新后不恢复。取消待确认不会清空原始文字，方便重新修改识别。
- 多标签页会广播刷新，编辑前会核对更新时间，但极短间隔的多标签页并发写入不是完整的冲突协议；请尽量只用一个页面修改同一记录。未来云同步必须设计服务端版本比较。
- 必要/非必要不是价值判断，最终以个人选择为准。

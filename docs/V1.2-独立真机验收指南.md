# 小账 V1.2 独立手机验收：只用 8444

## 保护原账本

这是独立测试包，网页固定 HTTPS 8444，证书、私钥和进程记录另存于 Mac 的 `~/Library/Application Support/LittleLedger-V12-8444-Acceptance`。不读取、替换或清理旧工具目录；不要把 site 复制到旧验收文件夹。不要操作原 https://192.168.0.156:8443 ，不要清除 Safari 网站数据、卸载 PWA、导入旧备份。旧账目异常 DATA-001 仍阻塞正式发布。

不同端口是不同浏览器来源，8444 的新空账本是预期现象，不能据此判断 8443 是否有数据。新包不包含 HTTP 4173 启动器，避免误入原电脑账本。所有验收只用虚拟消费。

## 下载与启动（无需 Node）

1. 下载 https://github.com/silleney/helloworld/raw/refs/heads/v1.2-mobile-data-safety/acceptance/小账-V1.2-8444-独立验收包.zip ，在 Finder“下载”文件夹双击解压，保留这个独立新文件夹。
2. Mac 和 iPhone 连接同一可信私人 Wi-Fi，不用访客网或酒店 Wi-Fi。不开放公网端口。
3. 双击新文件夹的 Prepare-iPhone.command。它通过受验证 HTTPS 下载固定 mkcert 1.4.4 并校验 SHA-256，在你的 Mac 本地生成 V1.2 专用 CA/私钥，不安装 Mac 系统 CA 信任、不上传证书或账目。记下终端显示的 SHA-256 指纹和 https://你的MacIP:8444 。
4. 若 macOS 阻止已下载的脚本，先确认它来自上面的仓库下载，再用 Finder 右键→打开；只使用系统正常的打开确认。若仍被阻止，停止并反馈，不关闭 Gatekeeper，不执行绕过安全保护的命令。
5. Finder 会定位新目录的 iPhone-Test-CA.cer。只把这个公开证书通过 AirDrop 发给 iPhone。绝不发送含 key 的文件。不能使用旧目录里的同名证书。
6. iPhone 接收后，到“设置→已下载描述文件”，或“设置→通用→VPN 与设备管理”打开待安装证书；核对它是刚传送的 mkcert 测试 CA，并在证书详细信息中核对 SHA-256 指纹。如系统提供的指纹格式不同、无法确认是哪张证书，请停止反馈，勿凭相似名称信任。点安装，输入设备密码，再确认安装。
7. 到“设置→通用→关于本机→证书信任设置”，只开启这张新测试 CA 的完全信任。CA 信任能让持有其私钥的人签发被手机信任的证书，所以私钥必须留在 Mac 且不分享；信任仅用于短期验收。旧 CA 信任保持不动。
8. 双击新文件夹 Start-iPhone.command，终端前台保持运行。若防火墙询问 Python 入站权限，在可信私人 Wi-Fi 测试期间允许。服务只绑定当前私人 Wi-Fi IP、只读提供静态网页；同一可达局域网的其他设备可能读取网页，但账本在各自浏览器，不会上传共享。不要关闭整个防火墙。
9. 在 iPhone Safari 普通标签页输入终端打印的完整地址，确认结尾是 :8444。不要打开旧收藏的 :8443，也不要添加或卸载主屏幕 PWA。证书警告时停止，不忽略警告。

## 验收步骤

1. 首页为一张浅紫金额卡片，金额及快速记账入口尽量首屏可见。流水、统计应有一致配色，无英文装饰标题；无横向溢出。
2. 手动输入“买菜¥38，零食￥25”，或系统键盘听写同类虚拟消费，识别两笔，合计 63.00。确认前不入账。修改金额、日期、分类，取消应保留原文；再识别并保存。
3. 核对最近记录、流水和统计；刷新 8444，核对笔数、金额、分类、日期。也测试手动记账和重复保存保护。此来源仅保存虚拟记录。
4. 无金额、负数、超精度输入要就近提示，保留原文；错误时不应编造金额。
5. 测试键盘、Safari 工具栏、底部安全区域、缩放、多笔确认、长金额和横屏。允许自然滚动，不能遮挡最终操作。
6. 导出新的测试 JSON/CSV，保存为 V1.2-test 等新名称，不覆盖原备份。如果要测恢复，只使用这份虚拟测试 JSON，在 8444 恢复；不在 8443 导入任何文件。
7. DATA-001 尚未调查，不能用这里通过的测试宣布旧账目安全。真实 Safari 跨版本缓存更新还需单独虚拟来源的后续验收，本包本身不是旧来源升级测试。

## 停止与撤销信任

双击新文件夹 Stop-iPhone.command，只停止本工具进程并释放 8444；也可在其前台终端按 Control+C。不终止旧服务或长期后台运行。

测试结束后，在 iPhone“证书信任设置”关闭刚安装的新 V1.2 CA 信任，再在“VPN 与设备管理”移除这一新证书描述文件。不要移除旧测试 CA，以免影响保留的 8443 调查环境。如果无法区分，先停止服务并反馈，不猜测删除。

然后双击新文件夹 Cleanup-iPhone.command，确认要清理时输入 DELETE；它只清理 V1.2 本地工具/证书，不清理旧证书或 Safari 数据。CANCEL 不清理。下次重新 Prepare/安装新证书后才能继续测试。

## 兼容性界限

沿用已验收的 Intel Catalina/Python 2.7.9+ 或 Python3 标准库工具；固定 mkcert Darwin x86_64 最低 macOS 10.9，下载验证和 TLS1.2 前置检查保留。页面构建目标 Safari 15.4+；iPhone 13 请使用支持该目标的 iOS。Linux 自动测试不能代替 Catalina Gatekeeper、系统 Python、AirDrop、iOS 描述文件、Safari 键盘和工具栏的真实验证。遇错停止反馈，不升级项目依赖或更改系统安全设置。

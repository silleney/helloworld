# 小账 V1.1：Mac Catalina 与 iPhone 13 验收

## 下载

打开 https://github.com/silleney/helloworld/tree/v1.1-mobile-redesign/acceptance ，点击 `小账-V1.1-局域网验收包.zip`，再点击 Download raw file（下载原始文件）按钮。也可直接打开：

https://github.com/silleney/helloworld/raw/refs/heads/v1.1-mobile-redesign/acceptance/小账-V1.1-局域网验收包.zip

在 Finder 的“下载”文件夹双击 ZIP 解压。无需 Node、npm、Homebrew。不要运行仓库的 npm 命令。

## 已有 Safari 账本：先备份，再更新页面

1. 在 iPhone 现有小账点“仅当前浏览器”，导出 JSON 完整备份，确认文件已保存到“文件”App；记下原访问地址，包括 `https://`、Mac Wi-Fi IP 和 `:8443`。
2. 保存或取消当前待确认账目。取消保留原文字；把未提交文字另行复制到备忘录，再清空输入框，确保允许更新。不要清除网站数据，不要删除数据库，不要使用无痕窗口。
3. 在 Mac 原验收文件夹双击 `Stop-iPhone.command`；如果电脑 HTTP 预览也在运行，停止其终端中的服务。
4. 将原文件夹中的 `site` 改名为 `site-V1.0-备份`。从新包复制整个 `site` 到原文件夹，文件夹名称仍须为 `site`。保留原启动脚本和证书。证书实际位于 Mac 用户 Library 下，本次网页替换不动它们。
5. 双击原文件夹的 `Start-iPhone.command`，核对终端地址与原地址完全一致，再在 iPhone 打开原地址。路径、IP、协议或端口改变都可能成为另一个本地账本；如果看到空账本，先核对地址，不要删除数据或反复导入。
6. 保持 Mac 服务运行且手机联网，刷新页面。旧 PWA 可能先显示旧页面，随后提示“新版本已准备好”；点“更新应用”。有未提交文字或待确认账目时按钮会禁用，请回到第 2 步。
7. 若暂时没有更新提示，关闭其他小账标签页和主屏幕小账窗口，再从原地址打开并刷新。不要清空 Safari 数据。仍无更新时停止验收并反馈。
8. 更新成功应看到手机首页“小账＋月份”和浅紫总额卡片。核对原记录、总额、分类、导出 JSON 与更新前一致，然后测试 `买菜¥38，零食￥25`，确认出现两笔候选。

如果 IP 已变化：优先在路由器维持原 Mac 地址。证书不匹配时停止，不忽略警告；必要时按原证书指南重新 Prepare，但新 IP 下浏览器账本来源会变化。原账本仍留在原来源；可在新来源通过先前 JSON 备份恢复，不能宣称自动迁移。

## 第一次使用 HTTPS 包

Mac 和 iPhone 连同一个可信私人 Wi-Fi。按包内 `README-iPhone.md` 的完整证书步骤操作：双击 Prepare、核对本地证书指纹、AirDrop 仅发送公开 CA、iPhone 设置中安装描述文件，再到“通用→关于本机→证书信任设置”只开启该测试 CA 的完全信任，然后双击 Start。

CA 和私钥只在你的 Mac 生成。没有上传或打包证书。不关闭 Gatekeeper、不开公网端口、不绕过 HTTPS 警告。原 CA 仍有效且已信任时，不必重复安装。防火墙提示允许 Python 入站，仅用于可信局域网的临时静态 HTTPS 服务；不允许时手机无法访问。网页不共享各浏览器账本。同网络设备可能读取公开网页，请只在私人 Wi-Fi 短期运行。

## 电脑端

新包双击 `Start.command`，访问原来的 http://127.0.0.1:4173 。若原电脑页面使用其他地址，不要混用。电脑仍显示原布局与配色；Catalina 的旧 Safari 版本不在生产代码 Safari 15.4+ 目标范围内，请使用此前已验收的同一电脑浏览器。本包不要求 Catalina 执行 Node。

## 人工验收

- 正常 Safari 视口无滚动尽量看到总额、两类金额、输入入口、识别按钮；320～430 宽度、放大文字、长金额无横向溢出和截断。
- 点击输入框适度展开；系统键盘听写“买菜三十八块，买零食二十五块”，检查转写符号金额可识别。
- 测试 ¥、￥、金额空格、38元、12块5、三十八元、混合多笔；核对描述、金额精度、笔数和合计。
- 识别后键盘收起；确认前不入账；修改内容、金额、日期、分类仍可用。非法金额合计显示待核对。
- 无金额、负数、超精度、范围金额要提示，原文保留且可修改重试。不要自动编造金额。
- 取消不保存、不清原文；保存成功更新概览和最近记录；连续点击不重复保存。
- 多笔展开可自然滚动；表单、按钮不被键盘或底部导航遮挡；返回流水和统计仍为原布局配色。
- 修改、删除、撤销、统计、刷新、JSON 备份恢复与 CSV 导出正常。CSV 用于查看，不是恢复格式。

## 结束与回退

双击 `Stop-iPhone.command` 关闭服务，终端不会后台长期运行。电脑 HTTP 服务用 Control+C 停止；如果不能停止，关闭其运行终端窗口并确认终止。

结束全部证书测试后，iPhone 在“证书信任设置”关闭该测试 CA 的信任，然后“通用→VPN 与设备管理”移除对应测试描述文件。Mac 双击 Cleanup 按说明确认清理，只清理本工具证书，不删除浏览器账目。下次测试须重新生成安装。

需要退回页面时先停止服务，将 `site-V1.0-备份` 换回 `site`，再使用相同地址和 PWA 更新流程。不要通过删除网站数据回退。

# V1.2 独立 iPhone 测试包

[直接下载 ZIP](https://github.com/silleney/helloworld/raw/refs/heads/v1.2-mobile-data-safety/acceptance/小账-V1.2-8444-独立验收包.zip)。也可打开同分支 ZIP 文件页，点击 Download raw file。

固定 HTTPS 8444，独立本地 CA、密钥与进程目录；仅使用虚拟账目，不触碰原 8443 来源。不要将新 site 复制到原验收目录。完整操作见 [指南](../docs/V1.2-独立真机验收指南.md)。DATA-001 未解除，不是正式发布。

开发者打包：`npm run build -- --target=safari15.4` 后运行 `python3 acceptance/build-v12-package.py`。旧 V1.1 ZIP 和工具保持不变。包不含 Node、HTTP 4173 启动器或任何私钥/证书；最终用户无需 Node。

开发者验证：将 v1.2-tools/verify-iphone-tools.py 复制到解压后的包根目录，以 Python3 执行并提供 Linux mkcert 路径。验证只在临时目录生成测试 CA，使用受信任 TLS 校验；测试端口 8444 须空闲。

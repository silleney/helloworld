## 已知限制

Linux 环境不能验证真实 iPhone Safari 键盘、工具栏、页面缩放、Gatekeeper、Catalina 系统 Python 和系统防火墙。WebKit 浏览器未安装，没有宣称 Safari 自动化通过。手机实机验收按另附指南完成。

HTTPS 工具沿用 iphone-acceptance 工具，业务代码基础仍是 main。工具固定 mkcert 1.4.4 Darwin x86_64（最低 macOS 10.9），下载保留 TLS 和 SHA-256 校验；Python 2.7.9+ / 3 标准库，启动强制 TLS1.2 能力检查。用户此前已通过此套工具的 Catalina/iPhone HTTPS 验收。云端复测使用 Linux Python3 与同版 mkcert，不等于在 Mac 上执行新包。

保守金额边界：不支持科学计数、千位分隔输入或范围金额；这些格式拒绝并要求手动填写。所有候选仍须核对描述、分类和金额。

未发布网站，未合并 main，未提供云同步。

HTTPS 云端复测通过：可信证书链/主机名、TLS1.2、全部静态文件校验、目录/私钥隔离、只读方法、重复启动、停止、无关 PID 保护、IP/权限拒绝和清理确认。验证脚本只在解压后的包目录运行（需 Python3 与 Linux mkcert），仓库 tools 目录不含 site，不能直接启动。
